4. Ranking Methodology

Each position scored on five factors, summed to a composite:

  • Valuation vs. Morningstar fair value (±2 pts; ±15% ≈ ±1) — live verified prices where available.
  • Morningstar star rating (2★ = −1 … 5★ = +2).
  • Analyst conviction (+1.5 for BUY-rated names from this desk's reports: AVGO, NVDA, TSM, GEHC, UBER).
  • Concentration penalty (−1 above 5%, −0.5 above 3%).
  • Income kicker (+0.5 for yields above 3%).

Scores are a ranking tool, not a valuation model. Star ratings and fair values are Morningstar's; targets on covered names are this desk's. Scores ≥ +1.5 → ADD consideration; ≤ −1 → TRIM consideration; judgment overlays applied (e.g., NVDA gated on price, AAPL tax-aware staging).
